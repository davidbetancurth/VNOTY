# VNOTY

Plataforma web para registrar, calificar y criticar novelas visuales.

## Estructura
- index.html: estructura de la página
- css/styles.css: estilos
- js/app.js: lógica y datos de ejemplo

## Uso
Abre index.html en el navegador (o usa la extensión Live Server de VS Code).

Código de desarrollador: constante CODE al inicio de js/app.js (cámbialo antes de publicar).
